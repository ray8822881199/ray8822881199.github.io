# 一平方的選擇權計算機

用瀏覽器建立小台、微台與台指選擇權部位，查看不同結算點位下的損益、原始／維持保證金及交易費用試算。

[開啟網站](https://ray8822881199.github.io/) · [AI 維護架構書](ARCHITECTURE.md)

## 可以做什麼

- 使用左側閃電表點選或拖拉建立選擇權部位，也能直接新增、編輯持倉。
- 比較持倉、測試倉與套用後的結算損益線圖。
- 試算單一部位及支援的兩腿組合保證金。
- 設定手續費，估算已建倉與已平倉的手續費、期交稅。
- 記錄部分平倉，匯出／匯入 CSV，透過分享連結傳遞持倉。
- 調整分析寬度、精細度與閃電表的履約價間距：50、100、150、200 點。

## 使用方式

1. 確認「大盤價平」。網頁會嘗試取得最近交易日的加權指數收盤價，也可手動輸入。
2. 在閃電表左鍵點選 Call／Put 建立買方、右鍵點選建立賣方；左鍵拖到另一履約價可建立一買一賣組合。直向小螢幕使用「新增組合倉位」開啟面板。
3. 填入類型、持倉點位、建倉成本及數量。選擇權成本和平倉價格以「點」輸入；期貨使用進出場指數點位。
4. 同一組合使用相同的「組合單代碼」。目前組合保證金支援同類 Call 買賣價差、同類 Put 買賣價差，以及賣 Call＋賣 Put；每組最多兩腿，建議兩腿口數相同。
5. 用「測試單」比較策略；「測試倉套用」將測試單轉成持倉。「是否計算」控制部位是否參與試算。
6. 離開前匯出持倉。網頁沒有自動儲存，重新整理會失去目前資料；CSV 匯入會加入現有持倉，不會覆蓋。

右側「分析寬度」是大盤價平上下的百分比，「精細度」是曲線取樣分段數，「閃電表寬度」是相鄰履約價的點數間距。這三項設定用途不同。

## 本機預覽

這是 HTML、CSS、JavaScript 靜態網站，沒有 npm 安裝或建置步驟。需要可連網的現代瀏覽器，以載入外部套件及行情資料。

若已安裝 Python 3，在專案目錄執行：

```sh
python -m http.server 8000 --bind 127.0.0.1
```

瀏覽 `http://127.0.0.1:8000/`，結束時按 `Ctrl+C`。也可以使用其他靜態 HTTP 伺服器；Python 不是網站的執行相依套件。

## 資料與限制

保證金是 `script.js` 內的固定參數，不會自動更新。目前記錄的期交所表格更新日期為 **2026-08-12**、查核日期為 **2026-10-13**；來源為[期交所保證金一覽表](https://www.taifex.com.tw/cht/5/indexMarging)。更新時須同步維護計算值與頁面日期。

損益圖是結算情境試算，未模擬時間價值、波動率或即時選擇權報價。未支援的組合目前可能被略過保證金計算；口數不相等的組合也沒有拆分剩餘部位。實際交易所需保證金及費用請以主管機關與期貨商為準。完整實作差異見架構書的「已知限制」。

CSV 適合本網站的一般持倉資料；組合代碼請避免逗號、引號與換行。分享連結包含可還原的持倉資料，不是加密備份，且不含手續費或畫面設定。網站也載入第三方分享、追蹤與廣告相關資源，請參閱[隱私政策](https://ray8822881199.github.io/privacy-policy.html)。

## 維護與驗證

修改前先閱讀 `ARCHITECTURE.md`，修改後同步更新相關文件。專案目前沒有持續整合或自動化測試套件。若本機有 Node.js，可先做語法檢查：

```sh
node --check script.js
git -c core.whitespace=cr-at-eol diff --check
```

再以瀏覽器檢查新增／移除持倉、閃電表四種間距、圖表、部分平倉、CSV 匯入匯出與分享還原；這些指令本身不驗證金融計算正確性。

私人持倉與本機產物請放入 `.gitignore` 指定的位置，不要提交真實交易資料。忽略規則不會移除已經追蹤的檔案。
